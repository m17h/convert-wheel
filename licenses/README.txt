Licence texts for the software inside Convert Wheel
===================================================

THIRD-PARTY-NOTICES.md, in the folder above, lists each component with its version, licence and project.

  ffmpeg\     FFmpeg (LGPL 3.0 or later), the libraries in it, where their source code is (SOURCES.md),
              and how to replace it with your own build
  Magick.NET* ImageMagick and its libraries, some of them LGPL
  pdfium\     PDFium and its libraries
  SkiaSharp*  Skia and its libraries
  dotnet\     Microsoft's terms for the .NET runtime, and its third-party notices
  the rest    one file per component
